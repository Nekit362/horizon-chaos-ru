# Проверка версии 0.2.0

- Две общие проверки `cargo check -p horizon-client --lib` прошли с WYR, Upgrader, графическими патчами и настоящим движком Orbital Laser.
- Первый `cargo build -p horizon-client --bin horizon-client` для Windows завершился успешно. После уточнения выбора одной из двух катастроф выполняется итоговая пересборка.
- WYR: 8/8 тестов, включая сохранение, запрет повторного ответа, обратный отсчёт и случайный выбор одной из двух катастроф.
- Upgrader: 6/6 тестов логики ставок и вращения.
- Визуальные патчи WYR: два теста помощников, проверка четырёх WGSL программ через Naga.
- Ресурсный пакет: 310 файлов, один manifest `wyr`, корректный JSON, отсутствие коллизий имён, детерминированная пересборка из оригинальных JAR.
- Полный игровой прогон этой версии пока не завершён.
