# Проверка версии 0.2.0

- Две общие проверки `cargo check -p horizon-client --lib` прошли с WYR, Upgrader, графическими патчами и настоящим движком Orbital Laser.
- Windows `cargo build -p horizon-client --bin horizon-client` завершился успешно после исправления загрузки ресурсов, стартовой выдачи и определения владельца мира. Оптимизированная сборка выполняется отдельно.
- WYR: 8/8 тестов, включая сохранение, запрет повторного ответа, обратный отсчёт и случайный выбор одной из двух катастроф.
- Upgrader: 6/6 тестов логики ставок и вращения.
- Визуальные патчи WYR: два теста помощников, проверка четырёх WGSL программ через Naga.
- Ресурсный пакет: 309 файлов, один manifest `wyr`, дополнительные namespaces `upgrader` и `orbital`; registry-предмет Upgrader объединён в `wyr:upgrader`. Штатный валидатор Horizon возвращает `ok:true`.
- Пересборка ресурсов из чистого опубликованного source checkout и двух оригинальных JAR даёт идентичный SHA256.
- Игра запущена с настоящим DirectX 12 renderer на GTX 1650 Ti, в отдельном мире, с копией подготовленных ресурсов26.3.
- При входе автоматически выдан один `wyr:upgrader`; открытие по U проверено.
- Реальная ставка: 64 алмаза → 1 акациевая лодка, шанс65%; колесо отображалось и вращалось, ставка списана, выигрыш получен единожды. Инвентарь подтверждён через control API.
- Обычная дилемма WYR проверена визуально: две карточки и русский текст.
- Центральная карточка катастрофы проверена визуально: «Удачи (Номер1)», «Чёрная дыра», отсчёт5; также зафиксирована карточка Meteor Storm под номером2.
- Автоматические реальные playback-запуски Sinkhole, Planet Killer и Meteor Storm зарегистрированы в журнале в координатах игрока. В этом прогоне использован `WYR_SMOKE_NO_TERRAIN=1`: разрушение блоков отключено.
- Выход из тестового мира корректно завершает активную катастрофу; реальные пользовательские миры и настройки не использовались.
- Полная визуальная проверка всех83 вариантов WYR, всех6 катастроф с разрушением ландшафта и многопользовательская проверка не выполнены.
